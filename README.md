# Dotify для iOS

Музыкальный плеер на Flutter: поиск и прослушивание музыки с YouTube Music без ключей и аккаунтов, фоновое воспроизведение и управление с экрана блокировки, очередь, перемешивание, повтор, любимые треки, радио по треку и автовоспроизведение похожих.

IPA собирается автоматически (GitHub Actions → вкладка **Releases**). Файл не подписан. Установка:
- **Sideloadly** (Windows/Mac) или **AltStore**: бесплатный Apple ID, переподписывать каждые 7 дней;
- **Feather / ESign** на iPhone, если есть свой сертификат.
