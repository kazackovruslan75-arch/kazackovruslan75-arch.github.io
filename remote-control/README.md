# PC Remote: управление ПК с телефона

Экран ПК в реальном времени, мышь, клавиатура (включая русский), горячие клавиши и громкость прямо из браузера телефона. Пароля нет.

## Запуск (Windows)
1. Установи Python с https://python.org (поставь галочку **Add Python to PATH**).
2. Скачай папку `remote-control` и дважды кликни `start.bat`.
3. В окне появится адрес вида `http://192.168.x.x:8000`. Открой его на телефоне (телефон должен быть в той же Wi-Fi сети).
4. Если Windows спросит про брандмауэр, нажми **Разрешить** (частные сети).

На ПК открывается по адресу `http://localhost:8000`. Linux/macOS: `./start.sh`.

## Управление
**Режим «Экран»** (по умолчанию):
- тап: клик в этой точке
- провести пальцем: перетаскивание
- долгое нажатие: правый клик
- два пальца вверх/вниз: прокрутка (в зуме они двигают картинку)

**Режим «Тачпад»**: палец двигает курсор, тап делает клик, тап двумя пальцами — правый клик, свайп двумя пальцами прокручивает.

Кнопки: ЛКМ/ПКМ, «Зажать» (удерживает ЛКМ), ⌨ открывает клавиатуру телефона, ⋯ показывает Esc/Win/стрелки/Ctrl+C/V/Alt+Tab, громкость, выбор монитора, качество, зум и полный экран.

⚠️ Пароля нет: любой в твоей Wi-Fi сети может открыть адрес и управлять ПК. Не запускай это в общественных сетях.
