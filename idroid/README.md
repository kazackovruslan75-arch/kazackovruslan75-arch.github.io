# iDroid Player

Android-эмулятор для **Windows** и **Linux** с Google Play, поддержкой 64- и 32-битных приложений, интерфейсом в стиле iOS и панелью инструментов как в BlueStacks.

## Возможности

- **Android x64 + x32 с Google Play.** Используется официальный Android Emulator (QEMU) и образы Google Play:
  - Android 11 x86_64 — рекомендуется: работают приложения `x86_64`, `x86`, `arm64-v8a` и `armeabi-v7a` (ARM через встроенную трансляцию);
  - Android 11 x86 — только 32-битные, для слабых ПК;
  - Android 13 / 14 x86_64.
- **Интерфейс iOS.** Свой домашний экран поверх Android: сетка иконок со скруглением iOS, док, поиск, строка состояния, обои, «полоска» Домой. Системные приложения получают iOS-иконки, остальные — иконки из Google Play с маской iOS.
- **Правая панель как в BlueStacks:** управление игрой, полный экран, громкость, поворот, скриншот, запись экрана, установка APK, эко-режим, несколько экземпляров, передача файлов, местоположение, встряхивание, Назад / Домой / Недавние, настройки.
- **Управление игрой (раскладка клавиш):** нажатие, крестовина WASD, обзор мышью (режим прицеливания), стрельба ЛКМ, повтор нажатий, свайп. Шаблоны для шутеров, MOBA и раннеров, отдельная схема для каждого приложения, экспорт/импорт.
- **Настройки:**
  - Производительность — профили, ядра ЦП, ОЗУ, эко-режим;
  - Частота кадров — **снятие лимита FPS** (дисплей 240 Гц, VSync в Android выключен), выбор 30–240 FPS, счётчик FPS;
  - Дисплей — **разрешение** (HD … QHD или своё), DPI, альбомная/книжная ориентация, автоповорот окна;
  - Графика — аппаратный рендер, ANGLE (DirectX), программный, Vulkan;
  - Устройство, звук и микрофон, сеть (DNS, прокси), горячие клавиши, оформление, ADB, сброс данных.
- **Менеджер экземпляров:** создание, клонирование, удаление, массовый запуск.
- Перетаскивание `.apk` в окно — установка, любых других файлов — копирование в `Download`.

## Установка

Готовые сборки создаются GitHub Actions (workflow **«iDroid Player — сборка»**) и доступны в артефактах:

- Windows: `iDroid-Player-*-win-x64.exe` (установщик) и `*-portable.exe`;
- Linux: `*.AppImage` и `*.deb`.

При первом запуске мастер скачает с серверов Google эмулятор, ADB и выбранный образ Android (~1,5 ГБ). Java и Android Studio не нужны. Если Android SDK уже установлен (например, вместе с Android Studio), его можно указать в мастере.

### Требования

- 64-битный процессор с виртуализацией (Intel VT-x / AMD-V), включённой в BIOS.
- **Windows 10/11:** включите компонент «Платформа низкоуровневой оболочки Windows» (WHPX) или установите *Android Emulator Hypervisor Driver*.
- **Linux:** KVM и доступ к `/dev/kvm`:
  ```bash
  sudo apt install qemu-kvm
  sudo usermod -aG kvm $USER   # затем перезайдите в систему
  ```
- 8 ГБ ОЗУ и больше, 10 ГБ свободного места.

## Если что-то падает

- Журналы лежат в папке данных приложения, подпапка `logs`:
  - Windows: `%APPDATA%\iDroid Player\logs\`
  - Linux: `~/.config/iDroid Player/logs/`

  `main.log` — само приложение, `inst….log` — эмулятор Android.
- Если эмулятор падает при старте, приложение само один раз перезапускает его в безопасном режиме (программная графика, холодная загрузка). Если помогло — выберите в настройках «Графика → Программный» или «ANGLE».
- Если падает интерфейс из-за драйвера видеокарты, со следующего запуска аппаратное ускорение интерфейса отключается автоматически. Можно отключить вручную: запустите с ключом `--disable-gpu`.

## Разработка

```bash
cd idroid
npm install
npm start          # запуск
npm run check      # проверка синтаксиса и разбора репозитория SDK
npm run dist:linux # AppImage + deb
npm run dist:win   # установщик + portable (на Windows)
```

Устройство приложения:

- `main.js` — главный процесс Electron: окна, IPC, запуск эмулятора;
- `src/sdk.js` — загрузка компонентов SDK из официального репозитория Google (без sdkmanager и Java), проверка SHA-1;
- `src/avd.js` — создание и настройка виртуального устройства (`config.ini`);
- `src/emulator.js` — запуск/остановка эмулятора, ADB, проверка виртуализации;
- `renderer/stream.js` — gRPC-связь с эмулятором: поток кадров экрана, касания и клавиши;
- `renderer/player.js` — окно эмулятора и правая панель;
- `renderer/springboard.js` — домашний экран iOS;
- `renderer/keymap.js` — игровое управление и его редактор;
- `renderer/settings.js` — настройки.

Ограничения: ввод кириллицы с клавиатуры ПК в Android не передаётся (используйте экранную клавиатуру Android); при большом разрешении и «Без лимита FPS» встроенный экран сильнее нагружает ЦП — в таком случае помогает выключить «Встроенный экран» в настройках графики.
